## What's new

- **Multiple content preview tabs.** Open files, images and websites alongside terminals, keep choosing files after opening a preview, adjust its width, and highlight code while preserving every line and space. Agents can open project and web previews through MCP.
- **A smoother saved-actions workflow.** Discover and review actions in one compact view, select all, edit individual entries, remove duplicates, and confirm from a fixed footer.
- **Third-party notification controls.** Toggle configured channels from the toolbar. Messages include time and session context; Windows WeChat delivery restores minimized windows and locates the configured contact.
- **macOS builds.** DMGs and app archives are available for Apple Silicon and Intel, with native terminal, account, notification and path handling.
- **Automated releases.** GitHub Actions tests and builds all desktop targets, packages the same Windows executable for npm, and verifies versions, source commits and checksums before publishing.

## 本次更新

- **多个内容预览标签。** 文件、图片和网站与终端并列打开，预览后仍可继续选文件，可调整宽度；代码只加高亮，保留原始换行和空格。Agent 可以通过 MCP 打开项目与网页预览。
- **常用操作流程更连贯。** 紧凑界面集中完成识别与审核，支持全选、逐项编辑、自动去重，确认按钮固定在底部。
- **第三方通知统一开关。** 顶部控制已配置的通知渠道，消息包含时间与会话信息；Windows 微信通知支持恢复最小化窗口并定位指定联系人。
- **提供 macOS 安装包。** 支持 Apple Silicon 与 Intel，适配原生终端、账号、通知和路径处理。
- **自动编译与发布。** GitHub Actions 运行测试、编译全部桌面版本，以同一次 Windows 主程序打包 npm，并在发布前校验版本、源码提交与校验和。

## Install / 安装

- Windows x64: download the EXE or MSI below. / 下载下方 EXE 或 MSI 安装包。
- macOS: choose `aarch64` for Apple Silicon or `x64` for Intel; app archives use `arm64` or `x86_64`. / 按芯片架构选择 DMG 或应用压缩包。
- npm (Windows): `npx termexo@0.11.0` or `npm install --global termexo@0.11.0`.
- Restart Termexo and Agent terminals after updating. / 更新后重启 Termexo，并重新打开 Agent 终端。

Windows packages are currently unsigned while the SignPath Foundation application is under review. macOS packages use ad-hoc signing and are not notarized; macOS may require allowing the app in Privacy & Security. macOS runtime behavior still needs verification on real devices.

SignPath Foundation 申请正在审核，当前 Windows 安装包未正式签名。macOS 安装包采用 ad-hoc 临时签名，尚未公证，首次运行可能需要在“隐私与安全性”中允许打开；运行体验仍需 Mac 真机验证。
